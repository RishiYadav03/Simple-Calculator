# Simple-Calculator
This is a basic calculator web application built using HTML, Bootstrap, and JavaScript. The interface is designed with Bootstrap for a clean and responsive layout, making it usable across different screen sizes, including mobile devices.

HTML for the structure,

Bootstrap for responsive and clean styling,

JavaScript for the calculator’s logic and interactivity.

🛠️ Features:

User-friendly interface with number and operator buttons.

Real-time display of user input and calculation result.

Responsive layout that works on both desktop and mobile.

📱 How it Works:

The user enter's values.

Pressing the (+, −, ×, ÷) button evaluates the expression using JavaScript.

The result is shown instantly in the display area.

This calculator is perfect for practicing JavaScript DOM manipulation and building interactive web elements using Bootstrap.
